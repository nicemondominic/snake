# Snake Evolution 🐍

A polished Snake game built with Python and Pygame.

### Features
- Classic, Hardcore and Survival modes
- Animated snake head and eyes
- Three food types: normal, gold, speed
- Shield power-up
- Combo scoring and progressive levels
- Dynamic obstacles
- Particle effects, screen shake and visual feedback
- Persistent high score
- Pause, restart and menu
- No external image/audio assets required

### Install
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### Controls
`WASD / Arrow Keys` move • `P` pause • `R` restart • `ESC` menu
